## Описание

Дополнение макета страницы из ЛР №2 с использованием Flexbox и CSS Grid. Добавлены навигационное меню, секция «Гипотезы исследования» с flex-карточками и секция «Методы исследования» с grid-дашбордом.

## Что сделано

- **Flexbox:** горизонтальное адаптивное навигационное меню (`<nav>`) и карточки «Гипотезы исследования». Каждая карточка содержит формулировку гипотезы и статус.
- **CSS Grid:** дашборд «Методы исследования» — 3 блока в сетке (3/2/1 колонки в зависимости от экрана). Каждый блок содержит иконку, название метода, краткое описание и раскрывающееся полное описание через `<details>` + `<summary>`.
- **Медиа-запросы:** для планшетов (≤768px) и мобильных (≤480px). Горизонтальная прокрутка отсутствует.
- **Контрастность:** тёмно-синий текст на белом и светло-голубом фоне — ≥ 7.5:1.
- **Семантика:** использованы `<nav>`, `<article>`, `<details>`, `<summary>`.

## Запуск

Открыть `index.html` в браузере или через GitHub Pages.
